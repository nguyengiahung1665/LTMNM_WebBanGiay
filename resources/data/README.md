# Vietnam address data

`vietnam-addresses.json` contains 34 provinces/cities and 3,321 commune-level units under Vietnam's post-2025 two-level administrative structure.

Source: [Open Admin Data – Vietnam Administrative Divisions](https://github.com/open-admin-data/vietnam-administrative-divisions), licensed CC BY 4.0. The project stores a reduced `{code, name, wards}` representation for offline form usage.
